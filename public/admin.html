Users are distinct visitors, estimated from IP addresses (stored only as one-way hashes; IPv6 counted per /64). Shared connections count as one, mobile and VPN users can count more than once. Every box follows the selected range: countries, clients and setups count each person active in that range once, using their latest known setup. Days end at midnight UTC. Server figures are read from the machine itself every 15 seconds (CPU, load, memory and uptime for the whole VPS; CPU limit and container memory from this container); “now” is the latest reading.
